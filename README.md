# Air Power Domination

## Game Overview
- **Concept**: Multiplayer PvP RTS game set in a desert environment where two teams of 4 players compete to destroy each other's command center using air raids and infantry assaults.
- **Genre**: Real-Time Strategy (RTS) with mechanics inspired by Battleship.
- **Target Audience**: Young adults aged 18-21, targeting casual players.
- **Unique Selling Point**: Emphasis on teamwork; no single player can carry the team.
- **Platform**: PC with LAN multiplayer.

## Gameplay & Mechanics
- **Roles**: Players take on roles like Engineer, Weapons Specialist, Guard, and Commander.
- **Buildings**: Command Center, Watchtower, SAM Site, Aircraft Hangar, Runway.
- **Core Mechanics**: 
  - **Preparation Phase**: Instant building with limits.
  - **Action Phase**: Airstrikes, recons, and attacks enabled.
  - **Game Over**: Building disabled, game ends when Command Center is destroyed.
- **Movement Controls**: WASD for camera, mouse for unit selection and movement.
- **Map Layout**: 130x10 grid with 20-cell size.

## Setting, Story & Characters
- **Setting**: Near-future desert environment with two factions at war.
- **Story**: Post-apocalyptic world where nations fight over scarce resources.
- **Characters**: Commander, Engineer, Weapon Specialist, and Guards, each with unique roles and backstories.

## Levels
- **Design**: Two levels (Tutorial and Game Level) with PvP elements.
- **Challenge**: Difficulty increases as players learn each other's tactics.

## Interface
- **UI**: Designed to support player decision-making with tools for commanders and unit controllers.

## Technical
- **Engine**: Unity.
- **Scripting Language**: C#.
- **Networking**: Unity Netcode for LAN multiplayer.

## References
- **Inspiration**: Company of Heroes 2, Battleship Online.
- **Art Style**: Low-poly military and desert themes.
